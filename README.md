# wp-snippets

Kho đoạn code dùng lại: tìm kiếm, icon giỏ hàng/tài khoản, bộ lọc sidebar sản phẩm, nút liên hệ nổi, popup…

## Cài / dùng

Mở thư mục tương ứng, chép đoạn cần dùng vào `functions.php` của theme con hoặc một plugin riêng; shortcode dùng như `[ten_shortcode]`.
